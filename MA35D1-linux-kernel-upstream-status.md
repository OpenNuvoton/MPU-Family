# MA35D1 Linux kernel upstream status

## Status definitions and scope

- **Reviewed-by**: A human review tag. Any conditions attached to the tag are noted separately. A review tag does not establish that a patch has been merged.
- **AI reviewed**: Sashiko has reviewed the patch. Findings are potential issues, not confirmed bugs or maintainer acceptance.
- **Applied / queued**: Requires a maintainer response or a commit in the maintainer's tree. Successful application to a Sashiko review baseline does not count as upstream acceptance.
- **Mainline merged**: Requires a confirmed commit in Linus's tree. A target kernel version is distinguished from an actual release containing the change.
- Dates use Asia/Taipei. `N/N` indicates a series containing N patches, excluding the cover letter. Patch numbering can change between revisions.
- This report documents upstream progress; no build, hardware, or functional tests were performed. Failure to find an acceptance record does not prove that no such record exists.
- **Last incremental check: 2026-10-30**. Sashiko and public archive/mirror searches were checked for changes after the 2026-10-28 report; only the EADC item changed.
